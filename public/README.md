# Public Assets

This folder contains publicly accessible files for your portfolio website.

## Files to add:

### resume.pdf
Replace this with your actual resume PDF file. The download button on the hero section links to `/resume.pdf`.

To add your resume:
1. Export your resume as a PDF (name it `resume.pdf`)
2. Place it in this `public/` directory
3. The download button will automatically work

### Favicon
To add a custom favicon:
1. Create a 32x32 PNG image (your logo/initial)
2. Name it `favicon.ico`
3. Place it in this `public/` directory
4. Update the favicon reference in `app/layout.tsx` if needed

### robots.txt
Already included. Update the sitemap URL to your actual domain.

---

**Note:** All files in the `public/` folder are served at the root of your domain. For example, `public/resume.pdf` is accessible at `yourdomain.com/resume.pdf`.
